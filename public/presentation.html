Mushroom Illusion

Diffusion Canvas Tool

LIU YA JING 刘雅静 mc569037 | JIANG CHUNWEI 姜春蔚 mc569121 | LI XINYUE 李欣玥 mc569227

01 Development Reasons

In visual communication, we often need to find suitable design solutions for posters or social media main visuals. The gradient technique is a commonly used method.

The traditional process often requires continuous adjustments of light perception and composition in design software. This tool is designed to simplify this cumbersome process, making the transformation from "idea" to "usable image" more rapid and effortless.

02 Work Application

Early Exploration

Quickly generate mood boards and atmosphere backgrounds.

Brand Extension

As a visual material master, batch generate a series of illustrations with consistent style.

Post-Composition

Supports transparent background PNG export, facilitating the superimposition of text and graphics.

Dynamic Output

One-click record the canvas, producing dynamic visual materials.

03 Design Thinking Process

Interaction

With gesture trajectories as the main body, establish the connection between actions and images.

Visual

Algorithmically simulates the change of diffused light clusters along the gesture to ensure the uniformity of dynamic textures.

Control

Add halo, color, presets, and undo/redo to enhance controllability.

Delivery

Integrate canvas export and video recording to break the loop.

04 Design Decision

Structure

Sidebar page navigation (canvas/gesture/color/export), achieving efficient single-screen operation.

Guidance

Language selection on the first page to reduce the understanding threshold for users across languages.

Error Tolerance

Gesture page integrates "clear + undo/redo", supporting frequent trial and error exploration.

Presentation

Color presets + real-time adjustment of size with the scroll wheel, allowing the effect to be presented intuitively.

The core of these decisions is to reduce the difficulty of use, enabling the generation of desired visual elements quickly and simply.

05 Development Process

Ideation & Prototyping

During development, we first create a small prototype to verify the feasibility of the idea.

Feature Implementation

Then continuously add web functions, building out the core features one by one.

Testing & Detection

Test and detect the effect and operation of web generation for any problems.

Iteration & Refinement

Continuously make adjustments based on feedback and optimize the user experience.
